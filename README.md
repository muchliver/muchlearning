## 🎯 8 大核心題型支援

1. 🔤 **克漏字選詞造句**：句子關鍵詞挖空，提供 4 個選項（含注音與釋義導引）。
2. 🔍 **造句錯字訂正**：融入常見形音義易錯字（按部/步、名列前茅/矛、迫不及/急等），提供選擇與手寫訂正欄。
3. 🧩 **重組造句**：自然語法切割為甲、乙、丙、丁 4 個詞組塊，支援排序選擇題與手寫排序格。
4. 📝 **短語照樣造句**：純例句自由創意仿寫，保留開放性語文素養，提供充裕仿手寫橫線。
5. 🔗 **關聯詞複句邏輯選擇**：因果、轉折、遞進、假設複句邏輯連詞選擇。
6. 🔤 **國字注音辨別**：看音寫國字 / 看字選注音雙向辨別題。
7. 🔄 **近義詞替換與詞義辨析**：文句相近詞替換與語境代換解析。
8. 🎭 **成語生活情境素養題**：生活日常對話情境成語應用題。

## 🖨️ A4 練習券與解答券列印引擎

- **試卷抬頭客製化**：可自訂試卷主標題、副標題、年級、座號、姓名與無拘束得分手寫欄。
- **題數自由選配**：10 題（剛好 1 頁 A4）、15 題、20 題、25 題（保證 100% 題數精準對齊）。
- **版面配置**：
  - **單欄整頁模式**：大字體、作答橫線格寬敞，適合國小學童與低年級書寫。
  - **雙欄密集模式**：節省紙張，適合題數較多（20 題以上）之測驗。
- **獨立解答券 (Answer Key)**：末頁自動產生獨立解答頁，包含每題正解選項、錯字對照、重組完整句子與批改標準指引。
